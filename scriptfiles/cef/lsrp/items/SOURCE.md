Item images `water_bottle.png`, `sandwich.png`, and `bandage.png` are from [SwisserDev/fivem-inventory-icons](https://github.com/SwisserDev/fivem-inventory-icons), `png-256/`.

The icon pack is released under [CC0 1.0 Universal](https://github.com/SwisserDev/fivem-inventory-icons/blob/main/LICENSE). These three files are included locally so the CEF inventory does not depend on an external image server.

`pistol_ammo.png`, `shotgun_ammo.png`, `rifle_ammo.png`, and `smg_ammo.png` are from the same CC0 pack, `png-256/`. The pistol icon covers both 9mm and Desert Eagle rounds. The local firearm SVG silhouettes remain as fallbacks if a firearm PNG cannot load.

The five `*_fivem.png` firearm images are downloaded from the free [SwisserAI FiveM icon library](https://ai.swisser.dev/fivem-inventory-icons), which explicitly allows using its downloadable icons on a server. They are local PNG assets, so inventory rendering does not need a network connection. These assets are separate from the CC0 GitHub pack above:
